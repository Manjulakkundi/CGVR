EXPERIMENT 9 - Simple interactive 3D scene (Unity)

1. Extract this zip fully.
2. Unity Hub > Projects > Add (next to New project) > Add project from disk > select the Exp9Unity folder (the one that contains Assets).
3. If Hub shows a version warning, pick any Unity editor you have installed (2021.3 LTS or newer) and continue/upgrade.
4. Open the project. First load takes a few minutes. The scene is built automatically.
   (If not: top menu Lab > Build Experiment 9 Scene)
5. Press Play. W A S D move, Space jumps, touch yellow cubes to score, left-click any object to recolor it.

If the Console shows an Input System error:
Edit > Project Settings > Player > Other Settings > Active Input Handling = Both, restart Unity.
